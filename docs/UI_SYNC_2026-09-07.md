# LCD 同步 HPM6750 最新界面

参考 `C:/projects/hpm6750-psk-modem/app/ui/display.c`，提交 `c84c683eb9e282c3ff7c819623f7a4f1d4078abb`。该仓库未修改。

本文保留首次 LCD 布局同步的历史记录。**同日后续已实现 Image/Audio 收发与手机页面**，当前行为和最新固件以 [图片和语音移植记录](IMAGE_AUDIO_2026-09-07.md) 为准。

## 界面与交互

- 顶部使用 Rx/Tx、Text/Image/Audio 和模式下拉框，替换旧版右侧模式按钮矩阵。模式先选 BPSK/QPSK/8PSK 家族，再从向左展开的列表选择具体模式，覆盖全部 28 个模式。
- 左侧保留当前模式、频率和信号峰值，瀑布图基准高度从 150 增加至 300，频谱数据和刻度从 0–3 kHz 扩展到 0–4 kHz。2000 Hz 中线对应最新 HPM 布局，点击瀑布图仍可调谐至 100–3500 Hz。
- 右侧改为 Rx Content / Tx Content，支持文本自动换行和滚动。旧 CQ/BER/ASCII/LOOP 屏幕按钮移除，对应 `TXSEL` 串口命令保留。
- HPM 的 800×480 布局适配 P4 的 1024×600；字体为 18/26 px，标题标识实际设备 ESP32-P4。LCD 与触摸驱动继续使用 P4 BSP，LVGL 在 core 1，瀑布图画布使用 PSRAM。
- LVGL 回调与 UI 任务之间读取待处理事件时使用显示锁；菜单展开期间，周期状态刷新不会改动正在选择的条目。关闭子菜单不提交模式变更。
- **本次同步界面，不包含 HPM 图片或 AP580 音频协议。** 选择 Image/Audio 会提示尚不可用并保持 Text，不改变实际调制模式，不把普通文本当作图片或音频处理。
- 补齐物理按钮模式轮换中的 `2x8PSK1200F`，串口预置文本和默认频点提示统一为 2000 Hz。

## 验证

`tools/preview_lcd.ps1` 使用仓库实际 LVGL 9.5.0 和生产 `main/display.c`，仅替换 BSP 初始化、内存分配与锁，生成 1024×600 帧缓冲截图。

- 全部 28 模式的选择和待处理事件读取通过。
- 子菜单取消、菜单打开时刷新、Rx/Tx 切换、未支持内容保持 Text 通过。
- 向实际 `spectrum_analyze` 输入 3500 Hz 正弦，检测峰值为 3500 Hz，扩展频段包含实际 FFT 数据。
- 检查空闲、接收文本、家族列表、8PSK 子列表、TX 内容和未支持提示的截图，文字和菜单没有裁切。截图信号与文本是预览样例，不是板上接收数据。
- ESP-IDF 固件编译通过，COM21 识别为 P4 v3.2，烧录写入校验通过。
- 重启日志包含 `HPM6750 c84c683 dropdown UI, scaled to 1024x600`，音频接收任务、C6 SDIO、AP/HTTP/DHCP 启动成功。`STATUS` 返回 RX / BPSK31 / 2000 Hz，`RXDIAG` 有响应；一个客户端已关联 AP。
- 尚未远程操作实物触摸屏；以上交互检查由主机 LVGL 执行。本次不新增模拟链路 BER 或高速实时性能结论。
